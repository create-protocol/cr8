# cr8

Coordination repo for the **Create Protocol / CR8 V4 revival**. Strategy docs, research outputs, and the bootstrap for the core on-chain components (agent registry, CR8-USD stablecoin with burn-toll, staking / yield-bearing NFTs).

Contracts live in sister repos — this repo is the place the strategy converges, research lands, and specs get written.
